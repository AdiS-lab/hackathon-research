### Recurring Project Archetypes That Win

1. **Medical diagnostic assistant** — Image/sensor input -> AI analysis -> differential diagnosis
   - Examples: Hearti, OncoAI, OncoBot, SentinelCV, Noma, SurgeVue, MedEase

2. **Accessibility bridge** — Translates between modalities for disabled users
   - Examples: SignVerse, SoundSense, BlinkAI, BrailleBot, Optica, VisionNav, Show and Tell

3. **AR-enhanced professional tool** — Snap/Quest AR for specific work context
   - Examples: FirefightAR, EnforcAR, Bob, Good Samaritan, SafeSnap, InterViewAR

4. **Autonomous robot doing specific task** — Physical robot with AI brain
   - Examples: Baymax, Artificial Sandwich Intelligence, OmNom, HarvestHero, Recollect, Hardware Context Protocol

5. **AI agent workflow / orchestration** — Multiple agents collaborating
   - Examples: Ensemble, deCluttered.ai, Bazaar, EDFlow AI, Relay, AgentZero, Electra

6. **Gamified behavior change** — Game mechanics driving real-world outcomes
   - Examples: Wattson, GitPets, bons.ai, TerraQuestt

7. **Safety/emergency tool** — AI-powered threat/hazard detection and response
   - Examples: HawkWatch, Watchful.AI, SafeWay, DriveWise, Meshworks, Orion

8. **Smart campus/personal tool** — Solves a specific student pain point
   - Examples: EasySplit, StudySuite, Minti, CoffeeStarter, FocusFlow

### Key Insight: What Separates Grand Prize from Track Prize

| Grand Prize Winners | Track Prize Winners |
|--------------------|--------------------|
| Hardware + AI + social impact | Software-only AI tool |
| Live interactive demo | Screenshot/slides demo |
| Novel interaction modality | Standard web/mobile UI |
| Multi-system integration | Single API wrapper |
| Specific problem, deeply solved | Broad platform, shallow depth |
| Team of 3-4 with clear roles | Solo or duo |
